# Qt 实时输入曲线参考模块

## 一、这个参考包是什么

本包演示如何在 PyQt6 界面中，使用鼠标手动绘制风速、太阳辐照等时序输入，并让其他程序在曲线改变时立即收到通知。

Qt 本身提供 `QWidget`、`QPainter`、鼠标事件和信号槽，但不会直接提供一个完全符合“分钟采样点 + 工程量限幅 + 鼠标连续绘制”的业务控件，所以这里用一个小型自定义控件来实现。

这是一个独立参考模块，不依赖极地微电网程序、数据库或 TCP 通信。

## 二、包内文件

- `curve_data.py`：曲线配置、数据点、线性插值以及 JSON/CSV 读写。没有 Qt 依赖，可以单独学习。
- `curve_widget.py`：使用 `QWidget + QPainter` 实现的鼠标手绘曲线控件。
- `demo.py`：同时编辑风速和太阳辐照的最小可运行示例。
- `使用说明.md`：当前说明文档。

## 三、运行环境

需要：

1. Windows、Linux 或 macOS。
2. Python 3.10 或更高版本，建议使用 Python 3.12。
3. PyQt6 6.7 或更高的 6.x 版本。

打开 PowerShell、Windows 终端或 Linux 终端，进入这四个文件所在目录，执行：

```bash
python -m pip install "PyQt6>=6.7,<7"
python demo.py
```

Windows 上如果 `python` 命令不可用，但安装 Python 时带有 Python Launcher，可改用：

```powershell
py -3 -m pip install "PyQt6>=6.7,<7"
py -3 demo.py
```

如果同学的原项目已经能够 `import PyQt6`，则不需要重复安装。

## 四、怎样操作示例

1. 在风速或太阳辐照曲线区按住鼠标左键。
2. 拖动鼠标修改曲线，快速拖动跳过的点会自动线性补齐。
3. 移动底部时间滑块，查看任意时刻的插值。
4. 可以将两条曲线导出为 JSON，再次加载；也可导出 CSV 供 Excel 查看。

## 五、如何调用控件

将 `curve_data.py` 和 `curve_widget.py` 复制到自己的 Python Qt 项目主目录，然后在界面代码中使用：

```python
from curve_data import CurveConfig, CurveData
from curve_widget import CurveEditor

config = CurveConfig(
    key="wind_speed",
    name="风速输入",
    unit="m/s",
    minimum=0.0,
    maximum=30.0,
    color="#2f80ed",
    sample_count=1440,             # 一天 1440 分钟
    sample_interval_seconds=60,    # 一分钟一个点
)

curve = CurveData.constant(config, 8.0)
editor = CurveEditor(curve)
self.someLayout.addWidget(editor)
```

这时 `editor` 就是一个普通 Qt `QWidget`，可放进 `QVBoxLayout`、`QGridLayout` 等任何布局。

## 六、如何实时接收曲线变化

`CurveEditor` 提供三个 Qt 信号：

- `pointChanged(index, value)`：某一采样点改变时发出。
- `curveChanged(values)`：拖画过程中实时发出整条曲线的副本。
- `editingFinished()`：鼠标松开、一次绘制完成时发出。

```python
editor.curveChanged.connect(self.update_preview)
editor.editingFinished.connect(self.save_curve_to_database)

def update_preview(self, values):
    print("当前共有", len(values), "个采样点")

def save_curve_to_database(self):
    values = editor.values()

```

不建议在每个 `curveChanged` 信号中都写一次数据库或发送 TCP，因为拖动时该信号会频繁触发。实时画面刷新可使用 `curveChanged`，真正保存更适合使用 `editingFinished`。

## 七、仿真运行时如何取值

曲线数据的 `value_at(seconds)` 会在相邻采样点之间做线性插值：

```python
simulation_seconds = 12 * 3600 + 30 * 60   # 12:30
wind_speed = editor.value_at(simulation_seconds)
```

宿主仿真程序可以在每个仿真步长调用它，然后将结果写入数据库或发送给其他端。

## 八、JSON 和 CSV 接口

```python
from curve_data import load_json, save_csv, save_json

save_json("curves.json", [wind_curve, solar_curve])
curves = load_json("curves.json")
save_csv("curves.csv", curves)
```

JSON 保留曲线名称、单位、上下限、采样规格和全部数据点。CSV 使用 UTF-8 BOM，可以直接用 Windows Excel 打开。

## 九、与 Qt Designer 配合

最易理解的方式是：先在 Designer 中放置一个普通 `QWidget` 作为占位区，界面加载后给该占位区创建布局，再调用 `addWidget(editor)`。这样不需要配置 Designer 提升控件，也更便于初学者调试。

## 十、功能边界

本参考模块只负责：

- 绘制和编辑输入曲线；
- 检查工程量上下限；
- 对鼠标跳过的采样点补间；
- 计算任意时刻的插值；
- 发出 Qt 信号；
- JSON/CSV 文件读写。

它不自动创建数据库，不自动发送 TCP，不代替仿真内核，也不直接控制真实设备。这些都应由各小组在自己的宿主程序中完成。

本参考实现面向 **Python + PyQt6**。如果选择 C++ Qt，不能直接导入这些 Python 文件，但可以按相同的 `QWidget + QPainter + mouseMoveEvent + signals` 结构进行移植。
